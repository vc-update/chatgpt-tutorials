## ChatGPT提示词大全2026：先掌握可复用结构

好提示词不是越长越好，而是把角色、任务、背景、输入材料、输出格式和限制条件写清楚。办公、写作、学习、编程和图片生成虽然场景不同，但都需要明确目标和验收标准。

## 怎么做：把模糊需求改成可执行提示词

1. 先写清楚你要完成什么任务。
2. 补充背景、受众、语气和限制。
3. 指定输出格式，例如表格、清单、邮件或代码块。
4. 要求模型先提问或先给大纲，再生成正文。
5. 输出后让模型按你的标准自检一遍。

## 注意事项：提示词使用禁区

1. 不要把敏感数据直接粘贴进去。
2. 不要让 AI 代替专业判断。
3. 不要一次要求完成太多复杂任务。
4. 不要只看第一版输出，应该追问和修订。
5. 图片提示词涉及商用时要复核版权。

## FAQ

### ChatGPT提示词有没有万能公式？

可以用“角色 + 任务 + 背景 + 输入 + 格式 + 限制 + 自检”作为通用结构，但每个场景仍要调整细节。

### 办公提示词怎么写更稳定？

说明文档用途、读者、语气、长度和输出格式。比如要求生成邮件、会议纪要、表格或执行清单。

### 编程提示词要提供什么？

要提供语言、框架、版本、报错、相关代码、目标和测试命令。上下文越完整，结果越可靠。

### GPT-Image-2提示词怎么写？

写清主体、场景、构图、风格、比例、文字要求和禁止项。中文海报文字建议少而准确。
