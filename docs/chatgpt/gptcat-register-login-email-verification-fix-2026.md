## 注册前先确认这四件事

### 1. 最终域名

搜索结果、广告或他人分享的链接可能跳转。进入后检查地址栏，确认页面属于 `gptcat.cc` 域名体系并使用HTTPS。相似Logo和页面样式不能代替域名核验。

### 2. 第三方身份

GPTCat不是ChatGPT官网，也不是其他模型厂商官网。它使用自己的账号、历史记录和服务规则，因此：

- 不要输入OpenAI账号密码；
- 不要输入Google或Apple恢复码；
- 不要把API Key粘贴到普通聊天页面；
- 不要假设不同平台的聊天记录会自动同步。

### 3. 邮箱是否能正常收信

使用一个你能稳定访问、收件箱未满的邮箱。具体支持哪些邮箱、是否需要验证码或其他验证，应以注册页当前提示为准。

### 4. 准备独立密码

密码应与OpenAI、邮箱、支付和工作账号不同。密码管理器可以帮助生成并保存唯一密码，但不要在共享电脑上开启自动登录。

## GPTCat邮箱注册步骤

页面布局可能变化，但判断逻辑基本一致：

1. 打开 `gptcat.cc` 并核对最终域名；
2. 进入注册或登录页面；
3. 输入可接收邮件的邮箱；
4. 按页面要求获取并填写验证码；
5. 设置独立密码或完成当前页面要求的验证；
6. 注册完成后退出一次，再重新登录确认账号可用；
7. 检查个人页面是否提供退出、密码修改或账号设置入口。

完成注册不代表需要马上上传文件。先用一句不含个人信息的公开问题测试，例如：

```text
请把下面这段公开文字整理成三条摘要，并列出你不确定的信息。
```

## 收不到验证码怎么办

按顺序排查，不要连续点击发送：

| 检查项 | 处理方法 |
|:---|:---|
| 邮箱拼写 | 核对用户名、域名和是否多了空格 |
| 垃圾邮件 | 检查垃圾箱、订阅邮件和推广分类 |
| 收件箱容量 | 删除无用大邮件，确认还能接收新邮件 |
| 邮件规则 | 检查是否自动转发、归档或拦截 |
| 等待时间 | 等待数分钟，只重发一次 |
| 频率限制 | 停止连续操作，按页面提示等待 |
| 页面域名 | 确认验证码来自你主动打开的正确页面 |

验证码是一次性安全信息，不要发给群聊、客服以外的陌生账号或所谓“代注册”人员。若页面没有明确错误但长时间收不到邮件，应保存时间和邮箱域名信息，通过平台公开支持渠道询问，不要把邮箱密码交给他人排查。

## GPTCat登录失败排查

### 提示密码错误

- 核对邮箱是否与注册时完全一致；
- 检查输入法、大小写和末尾空格；
- 不要在多个相似页面反复尝试；
- 使用页面提供的密码重置流程，而不是向他人发送密码。

### 登录后又回到登录页

这通常与Cookie、浏览器扩展或会话有关：

1. 用无痕窗口登录同一账号；
2. 暂时关闭网页翻译、广告拦截和脚本扩展；
3. 清理 `gptcat.cc` 相关Cookie，而非所有网站数据；
4. 检查系统日期、时间和时区；
5. 换另一个主流浏览器对照。

### 登录后空白或一直加载

先刷新并新开标签页，再测试另一浏览器和设备。如果只有一台设备异常，重点检查本机浏览器；如果多设备都异常，查看平台公告或联系支持。不要把第三方平台异常简单等同于OpenAI官方故障。

## 首次登录后怎么测试

不要只看模型菜单。用同一份公开任务完成下面四个测试：

### 测试一：普通中文问答

要求输出摘要、表格或改写，检查响应是否完整、中文是否自然、能否继续追问。

### 测试二：模型切换

如果页面提供GPT、Claude、Gemini、Grok或DeepSeek等分类，用完全相同的任务测试，并记录：

- 页面显示的模型名称；
- 输出速度与完整性；
- 是否遵守格式；
- 是否明确不确定内容；
- 切换后历史上下文是否保留。

页面标签不能单独证明底层模型来源或固定版本，重要任务仍需核对事实和来源。

### 测试三：文件或图片入口

仅上传你自己创建的低敏感测试文件。检查是否能删除文件、历史记录如何显示、页面是否说明支持格式和限制。需要处理PDF、Word或Excel时，可先看[ChatGPT文件上传排错方法](/chatgpt/chatgpt-chinese-web-first-prompt-file-image-task-tutorial-20260724)。

### 测试四：退出与重新登录

退出账号并重新登录，确认密码保存位置、浏览器共享状态和历史记录是否符合预期。共享电脑使用后应完整退出。

## 账号与文件安全清单

- 使用独立密码，不复用邮箱和OpenAI密码；
- 不提交验证码、恢复码、API Key和银行卡信息到聊天框；
- 先用公开、低敏感材料测试；
- 上传文件前删除姓名、电话、客户信息和内部数据；
- 记录当前域名、注册邮箱和登录方式；
- 定期检查浏览器中是否仍保持登录；
- 离开共享设备前退出账号并清理会话；
- 模型名称、额度和功能以当前页面为准。
