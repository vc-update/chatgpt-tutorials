## 通用结构

```text
主题：[你要生成的图片主题]
主体：[人物/产品/场景/物体]
场景：[背景、环境、时间、氛围]
构图：[近景/远景/俯拍/居中/留白]
风格：[真实摄影/插画/3D/扁平/科技感]
文字：[是否需要文字；如果需要，写准确文字]
比例：[1:1 / 16:9 / 9:16 / 4:3]
禁止：[不要 logo、不要水印、不要乱码文字、不要人物肖像]
```

## 电商产品图

```text
为一款[产品名称]生成电商主图。
产品位于画面中心，背景为浅灰色摄影棚，柔和阴影，高级质感。
突出[核心卖点]，画面干净，适合淘宝/独立站商品展示。
比例 1:1，不要生成文字，不要出现真实品牌 logo。
```

适合关键词：`GPT-Image-2 电商图`、`AI 产品图生成`、`ChatGPT 商品图`。

## 中文海报

```text
生成一张中文活动海报。
主题：[活动主题]
主标题：[准确中文标题]
副标题：[准确中文副标题]
风格：现代、清爽、有科技感。
构图：上方标题区，中间视觉主体，下方信息区。
颜色：[主色] + 白色留白。
比例 9:16，文字必须清晰，不要乱码。
```

中文海报要特别强调“文字必须清晰，不要乱码”。如果文字复杂，可以先让模型留白，后期用设计工具加字。

## 博客封面

```text
为一篇标题为《[文章标题]》的博客生成 16:9 封面图。
画面包含[核心元素1]、[核心元素2]、[核心元素3]。
风格：专业、明亮、适合 SEO 教程网站。
左侧保留标题留白区，右侧放视觉主体。
不要出现真实品牌 logo，不要生成乱码文字。
```

适合站长批量做文章封面。

## PPT 配图

```text
生成一张适合商务 PPT 的配图。
主题：[主题]
画面：抽象但易懂，包含[行业元素]和[数据/流程/协作]的视觉隐喻。
风格：简洁、现代、企业级、浅色背景。
比例 16:9，不要文字，不要复杂细节。
```

PPT 配图不建议让模型直接写很多字，最好生成视觉图，再由 PPT 里加标题。

## 短视频封面

```text
生成一张短视频封面。
主题：[视频主题]
人物/主体：[主体]
情绪：[惊喜/专业/高能/轻松]
背景：高对比、清晰、有层次。
标题区域：上方留出大字标题空间。
比例 9:16，适合手机端浏览。
不要生成乱码文字，不要水印。
```

## Logo 灵感图

```text
为[品牌/项目名称]生成 Logo 灵感图。
品牌关键词：[关键词1]、[关键词2]、[关键词3]。
风格：简洁、现代、可识别、适合科技产品。
输出为纯色背景上的图形标志。
不要模仿已有品牌，不要包含真实商标。
```

Logo 只能作为灵感草图，商业使用前要做商标检索和人工设计。

## 漫画头像

```text
生成一个原创漫画头像。
人物特征：[发型/表情/服装/气质]
风格：干净、可爱、现代插画。
背景：简单渐变或纯色。
比例 1:1。
不要模仿真实公众人物，不要出现文字。
```

## 提示词优化技巧

1. 先写清楚用途，再写风格。
2. 中文文字复杂时，优先让模型留白。
3. 商业图不要出现真实品牌 logo。
4. 同一个模板每次只改 2 到 3 个变量。
5. 多轮修改时明确“保留什么、修改什么”。

## 常见失败原因

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 文字乱码 | 文字太多或要求太复杂 | 减少文字，改为后期添加 |
| 构图混乱 | prompt 没有限制主体和布局 | 加“主体居中、背景简洁” |
| 风格不稳定 | 风格词互相冲突 | 保留 1 到 2 个主风格 |
| 商业风险 | 出现品牌/名人/版权元素 | 加禁止项并人工复核 |

## FAQ

### GPT-Image-2 提示词越长越好吗？

不是。越清楚越好，不是越长越好。主体、构图、风格、尺寸、禁止项最关键。

### 中文海报文字能一次生成好吗？

简单短标题更容易成功。复杂中文排版建议让模型留白，再用设计工具添加文字。

### 可以生成真实人物照片吗？

涉及真实人物、公众人物、肖像和商业授权时要谨慎，最好使用原创人物或抽象场景。
