## 一个稳定的 Prompt 结构

可以用这个公式：

```text
角色 + 任务 + 背景 + 输入材料 + 输出格式 + 限制条件 + 检查标准
```

示例：

```text
你是一个中文内容编辑。请根据我提供的资料，整理一篇 800 字以内的产品说明。
要求：语气清楚、适合新手阅读、用小标题分段、最后给出 3 个常见问题。
如果资料不足，请先列出需要补充的信息。
```

## 办公 Prompt 模板

### 周报总结

```text
请把以下工作记录整理成一份周报，分为：本周完成、关键进展、遇到的问题、下周计划。
语气保持专业，不夸大结果，每条尽量控制在 30 字以内。
```

### 会议纪要

```text
请根据以下会议记录生成会议纪要，包括：讨论主题、关键结论、待办事项、负责人、截止时间。
如果负责人或时间没有出现，请标记为“待确认”。
```

## 写作 Prompt 模板

### 文章大纲

```text
请围绕主题“{主题}”生成一份中文文章大纲。
目标读者是新手，文章要解决实际问题，不要只做概念介绍。
请包含标题、导语、5 个二级标题、FAQ 和相关文章建议。
```

### 改写润色

```text
请把下面这段文字改写得更清楚、更适合网页阅读。
要求：保留原意，减少重复，分成短段落，不使用夸张营销语。
```

## 学习 Prompt 模板

```text
请扮演一位耐心的老师，用中文解释“{概念}”。
要求：先用一句话解释，再举一个生活例子，最后给 3 道练习题和答案。
```

## 编程 Prompt 模板

```text
请阅读下面这段代码，解释它的作用、输入输出、潜在 bug 和可以改进的地方。
如果你建议修改，请先说明原因，再给出修改后的代码。
```

## 图片生成 Prompt 模板

```text
请帮我生成一段图片提示词，用于制作“{主题}”封面图。
要求包含主体、场景、风格、光线、构图、颜色、比例和不希望出现的元素。
输出中文和英文两个版本。
```

## 怎么复用这些模板

1. 把 `{主题}`、`{材料}`、`{目标读者}` 替换成自己的内容。
2. 输出格式越明确，结果越稳定。
3. 不满意时不要重开话题，直接追问“请按这个方向修改”。
4. 事实、数据、引用和代码结果都要人工复核。
5. 敏感资料不要直接粘贴到不可信页面。
