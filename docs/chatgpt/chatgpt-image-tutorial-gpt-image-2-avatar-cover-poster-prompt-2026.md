## ChatGPT生成图片教程：新手先看这5步

不管你用的是 ChatGPT 网页版还是可访问的多模型平台，生成图片的流程大同小异。新手照着这5步走就能出第一张图：

1. **登录并进入图片入口**：打开 ChatGPT 网页版或可用的多模型入口，登录账号。找到聊天输入框，图片生成通常直接在对话里发起，不需要单独的"画图"页面。
2. **确认是否支持 GPT-image-2**：在模型选择处查看是否有 GPT-image-2 / ChatGPT Images 相关选项。不同平台显示名称可能不同，以页面实际显示为准。如果没有图片能力，说明当前账号或入口暂不支持。
3. **选择图片比例**：想好成图用途再定比例。头像用 1:1，视频封面用 16:9，小红书竖版用 3:4，手机海报用 9:16。比例可以直接写进 Prompt。
4. **输入结构化 Prompt**：一次把主体、场景、风格、比例、文字、限制说清楚，别只写"帮我画个头像"。完整公式见下文。
5. **保存与二次修改**：出图后如果只有局部不满意，用"保持人物不变，只改背景"这类指令做局部迭代，而不是重写整段 Prompt 从头再来。

## ChatGPT图片生成Prompt万能公式

新手最容易犯的错，是把 Prompt 写成一句大白话。真正好用的结构是**九个字段填空**。记不住没关系，照着下面这张表填就行：

| 字段 | 作用 | 中文填写示例 |
| --- | --- | --- |
| 用途 | 告诉模型这张图干什么用 | 用于 LinkedIn 职业头像 |
| 主体 | 画面核心是谁/是什么 | 30岁左右亚洲男性，短发，戴眼镜 |
| 场景 | 主体所处环境 | 简洁办公室，虚化背景 |
| 风格 | 视觉调性 | 商务写实摄影风，自然光 |
| 构图 | 镜头/角度/取景 | 正面半身像，居中，浅景深 |
| 比例 | 成图尺寸 | 1:1 正方形 |
| 文字 | 需要渲染的文字内容 | 无文字（头像通常不加字） |
| 限制 | 不要出现的元素 | 不要过度美颜，不要卡通滤镜 |
| 输出要求 | 数量/清晰度/迭代 | 出1张，后续可局部修改 |

拼起来就是一段完整 Prompt。公式速记：**主体 + 用途 + 风格 + 构图 + 比例 + 文字 + 限制 + 修改要求**。字段越完整，出图越可控，反复重抽的次数越少。

## 头像生成Prompt写法

头像重点是"像本人的气质、不油腻、不塑料"。下面四类模板可直接复制修改：

**1. 真人职业头像**

用途：LinkedIn/简历职业头像。主体：35岁亚洲女性，齐肩黑发，浅妆，
自信微笑。场景：纯色浅灰背景。风格：商务写实摄影，柔和正面光，
真实肤质。构图：正面半身，居中，浅景深。比例：1:1。
限制：不要过度磨皮，不要美颜滤镜，保留自然细节。
**2. 卡通/插画头像**

用途：微信/社交平台卡通头像。主体：短发男生，戴圆框眼镜，
穿灰色卫衣。风格：扁平插画，暖色调，线条干净。构图：半身，
居中。比例：1:1。限制：不要写实，不要复杂背景。
**3. 社交媒体风头像**

用途：小红书/微博个人头像。主体：年轻女性，长发，元气感。
场景：柔光暖色背景。风格：日系清新摄影感，胶片质感。
构图：面部特写偏上，留白在顶部。比例：1:1。
限制：不要夸张滤镜，不要文字。
**4. 品牌 IP 头像**

用途：账号品牌吉祥物头像。主体：一只圆脸橘猫，戴耳机。
风格：3D 卡通渲染，饱和明亮。构图：正面居中，简洁背景。
比例：1:1。限制：形象友好可爱，不要写实猫。
头像避坑要点：**不要上传或要求生成明星、公众人物的脸做自己头像**，这涉及肖像权与身份冒用；**不要过度美颜**导致"不像本人"；卡通/IP 头像**不要模仿已注册的品牌形象**，避免商标侵权。

## 封面生成Prompt写法

封面的关键不是画面多炫，而是**标题文字清晰、留白到位、比例贴合平台**。不同平台比例不同，写 Prompt 时一定要指。

**公众号封面（横版，标题醒目）**

用途：公众号头图封面。主题：职场效率工具测评。风格：
简约扁平，蓝白配色，科技感。构图：左侧留白放标题，
右侧放图形元素。比例：3.35:1（公众号头图）或按平台要求。
文字：主标题"5个提效神器"，字体粗黑，居左。
限制：文字清晰可读，配色不超过3种。
**小红书封面（竖版，强吸睛）**

用途：小红书笔记封面。主题：新手化妆教程。风格：暖色
少女感，手写体点缀。构图：上方大标题，下方产品图，
留白居中。比例：3:4。文字：主标题"3步伪素颜"，
副标题小字。限制：文字不遮挡主体，颜色对比强。
**视频封面（横版，高对比）**

用途：B站/YouTube 视频封面。主题：AI 生图实测。风格：
深色科技感，霓虹高光。构图：人物在左，标题在右，
强对比。比例：16:9。文字：大标题"我用AI画了100张图"。
限制：远距离也能看清标题，避免小字。
**课程封面（专业感）**

用途：在线课程封面。主题：Excel 数据分析入门。风格：
稳重蓝灰，商务专业。构图：标题居中，底部放讲师信息栏。
比例：16:9。文字：课程名+"零基础到进阶"。
限制：排版整齐，层级分明。
封面提醒：中文标题一定要在出图后**逐字检查**，尤其是数字、书名号和专有名词，AI 渲染的中文偶尔会缺笔画或错字。

## 海报Prompt写法

海报信息多、层级复杂，最容易翻车。写法上要**明确文字层级**（主标题、副标题、时间地点、按钮），并预留二次修改空间。

**活动海报（竖版）**

用途：线下读书会活动海报。主题：周末读书分享会。风格：
文艺清新，米色纸质感。构图：顶部主标题，中部插画，
底部信息栏（时间、地点）。比例：9:16。文字层级：
主标题"周末读书会"，时间"7月20日 14:00"，地点"市图书馆"。
限制：文字准确清晰，留白舒适。
**产品海报**

用途：新品上市宣传海报。主题：无线降噪耳机。风格：
高端极简，深色背景，聚光灯效果。构图：产品居中悬浮，
上方标题，下方卖点三行。比例：3:4。文字：主标题产品名，
卖点"40小时续航 / 主动降噪 / 舒适佩戴"。
限制：卖点文字对齐，不堆砌。
**招聘海报**

用途：公司招聘海报。主题：招募新媒体运营。风格：活力
橙黄，年轻化。构图：顶部"WE ARE HIRING"，中部岗位，
底部投递方式。比例：3:4。文字：岗位名、职责要点、
联系方式。限制：信息分块清晰，别挤在一起。
**节日海报**

用途：中秋节品牌祝福海报。主题：中秋团圆。风格：国风
暖金，月亮与云纹。构图：居中月亮，两侧留白，底部品牌名。
比例：9:16。文字：主标题"月满中秋"，底部品牌名。
限制：氛围温暖，文字不喧宾夺主。
**二次优化指令示例**（海报调整最常用）：

- "保留标题文字和排版，把背景换成深蓝夜空"
- "保持整体布局不变，只把时间改成7月25日"
- "标题右侧增加留白，方便后期加二维码"
- "把底部信息栏字号调大，提高可读性"

## GPT-image-2生成图片常见翻车问题与修正

出图不满意别急着骂模型，多数问题有对应修法：

- **中文字错误/缺笔画**：把要渲染的文字用引号单独列出，减少字数，出图后人工核对；错字就用"把标题文字改为'XXX'，其余保持不变"。
- **手部/手指异常**：明确写"双手自然放置""避免手部特写"，或让主体动作避开手部。
- **比例不对/被裁切**：在 Prompt 里显式写比例，如"比例 9:16"，别只靠平台默认。
- **风格跑偏**：加风格锚点词（如"扁平插画""写实摄影""国风"）并减少互相冲突的描述。
- **人物不像本人**：真人头像建议少堆滤镜词，强调"真实肤质、自然表情"；不要指望 AI 100% 还原某个具体真人。
- **海报信息太乱**：用"分块""层级""对齐"这类结构词，把主标题、副标题、信息栏分开描述。

## FAQ

### Q1：ChatGPT 可以免费生成图片吗？
不同账号类型和平台的图片生成额度、是否免费各不相同，且经常调整。这里不给固定说法，请以你所用平台的实际显示为准，避免被过时信息误导。

### Q2：GPT-image-2 和 DAL-E 有什么区别？
在用户搜索语境里，GPT-image-2 常被看作 ChatGPT 图片生成能力较新的版本，普遍反馈是文字渲染和局部修改响应更可用。DALL-E 是较早的生图系列。两者的官方命名与替代关系各渠道说法不一，本文不擅自下定义，以平台实际显示为准。

### Q3：中文 Prompt 好还是英文 Prompt 好？
画面描述用中文完全够用，GPT-image-2 对中文理解不错。但**要渲染进图里的文字**建议单独用引号列出并核对；无论中英文，长句文字都可能出错，商用前人工校对。

### Q4：能不能用它生成商业海报？
可以做设计草稿，但不建议直接商用不检查。需自行确认文字准确性、素材授权、是否涉及他人肖像/商标，以及目标平台的政策。不要把 AI 生成图默认当成"无版权风险可直接商用"。

### Q5：为什么中文海报文字会错？
AI 渲染中文文字时，长句、生僻字、日期和品牌名容易出现缺笔画或错字。修法：减少文字量、用引号单列文字、出图后逐字核对，或用"把标题改为'XXX'"精准修正。

### Q6：如何让头像更像本人？
少堆美颜滤镜词，强调"真实肤质、自然表情、简洁背景"，并用局部修改逐步逼近。但 AI 无法保证 100% 还原某个具体真人，也不要拿明星或他人的脸生成头像。

### Q7：手机能用吗？
能。用手机浏览器打开 ChatGPT 网页版，或打开 [snakegpt.vip](https://www.snakegpt.vip/)、[gptcat.cc](https://gptcat.cc/) 这类可访问平台，在对话里输入 Prompt 即可。本站是教程博客，不提供生图功能，操作要在这些工具里完成。
