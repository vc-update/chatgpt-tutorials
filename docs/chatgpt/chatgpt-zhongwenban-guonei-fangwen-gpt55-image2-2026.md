## 四、GPT-image-2 的典型用法

GPT-image-2 更适合生成图像素材、教程配图、产品图、社媒封面和创意草图。提示词不要只写“生成一张好看的图”，最好写清用途、主体、场景、风格、构图和限制。

| 用途 | 提示词重点 |
|:---|:---|
| 教程封面 | 主题明确，留白充足，适合加标题 |
| 产品图 | 界面干净，场景真实，避免侵权标识 |
| 小红书封面 | 色彩明亮，主体清楚，避免乱码文字 |
| 办公配图 | 真实自然，突出效率和工具使用 |

示例 Prompt：

```text
请生成一张教程配图，主题是“GPT-5.5 与 GPT-image-2 使用指南”。画面为现代办公桌面，电脑屏幕显示 AI 对话界面，整体干净、专业、明亮。横版构图，保留标题空间，不要水印，不要乱码文字。
```

如果你需要同时使用 GPT-image-2 和 MJ 绘图，[GPTCat](https://gptcat.cc) 会比较适合；如果只是先整理图片提示词，SnakeGPT 也能完成很多前期文案工作。

## 五、推荐使用流程

一个更稳的流程是：

1. 用 GPT-5.5 拆解任务，生成思路和提示词。
2. 用 GPT-image-2 或 MJ 绘图生成视觉素材。
3. 回到 GPT-5.5，让它根据图片用途优化标题、说明和发布文案。
4. 人工检查事实、版权、隐私和品牌风险。

这样比直接“生成一张图”更稳定，也更适合长期复用。

## 七、安全注意事项

- 不要把第三方平台当作官方服务。
- 不要提交密码、私钥、身份证、银行卡和未公开合同。
- 上传文档前先删除真实姓名、电话、客户信息等敏感字段。
- 图片生成要注意肖像权、商标和版权。
- 重要结论要人工复核。

## 八、常见问题

### 国内访问 ChatGPT 中文版最重要的是什么？

最重要的是稳定、透明和安全。模型多不等于一定适合你，建议先用低风险任务测试，再决定是否长期使用。
