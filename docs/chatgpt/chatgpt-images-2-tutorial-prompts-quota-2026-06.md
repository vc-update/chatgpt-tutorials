## 适合生成什么图？

| 图片类型 | 推荐程度 | 说明 |
| --- | --- | --- |
| 博客封面 | 高 | 适合 SEO 站点和教程页 |
| 中文海报 | 中高 | 短文字更容易成功 |
| PPT 配图 | 高 | 建议不生成文字 |
| 电商主图 | 中 | 要注意产品真实性 |
| 头像插画 | 高 | 避免模仿名人 |
| Logo | 中 | 只适合灵感，不建议直接商用 |

```text

构图：左侧留标题区，右侧放视觉主体。

```

## 额度和限制怎么看？

不同账号、地区、模型和产品阶段可能有不同额度。建议用户按这个顺序核验：

1. ChatGPT 页面实际提示。
2. 账号套餐说明。
3. 生成失败时的错误提示。
4. 是否进入排队或冷却。
5. 是否需要升级或等待额度刷新。

不要把第三方文章里的额度数字当成永久规则。

## 常见失败原因

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 中文乱码 | 文字太多或排版复杂 | 少字，或后期加字 |
| 风格不稳定 | prompt 太散 | 固定风格和构图 |
| 出图慢 | 排队或网络问题 | 等待或降低复杂度 |
| 内容被拒 | 涉及敏感或版权内容 | 改成原创、安全素材 |
| 细节不对 | 需求不够具体 | 多轮修改，说明保留和修改 |

## 国内使用注意事项

1. 不要把第三方图片站当成 OpenAI 官方。
2. 不要上传身份证、合同、客户图片。
3. 不要把 API Key 填到免费生图网站。
4. 商业使用前检查版权、商标和肖像。
5. 重要素材建议人工二次设计。

## 中文图片提示词模板

可以直接按这个格式写：

> 生成一张 16:9 横版中文科技海报，主题是“ChatGPT 国内使用指南”，画面包含浏览器窗口、对话气泡、官网入口和安全盾牌元素，整体干净、现代、信息层级清楚。主标题不超过 12 个中文字符，副标题不超过 18 个中文字符，避免乱码，留出顶部标题区和底部说明区。

如果第一次生成不准，不要整段重写。更有效的方式是继续追问：“保留构图，只把标题改成……”“减少背景元素”“让中文文字更清晰”“把比例改成 4:3”。Bing 排名前面的图片教程普遍会写迭代方法，这比只给一个提示词更有用。

## 追加 FAQ：GPT-Image-2 搜索用户常问

### GPT-Image-2 和 ChatGPT Images 2.0 是一回事吗？

可以把它理解为同一类图片生成能力在不同场景下的叫法：普通用户关心 ChatGPT 里的图片生成入口，开发者更关心 OpenAI API、模型名称、参数和调用方式。

### GPT-Image-2 适合做中文海报吗？

适合，但提示词要控制文字长度。中文标题越短越稳，最好明确“主标题不超过多少字”“副标题不超过多少字”“不要出现乱码”，生成后再用多轮修改微调。

### 第三方在线生图站可以直接填 API Key 吗？

不建议。API Key 等同于账号权限，不要填到来路不明的网站。需要 API 调用时，优先看官方文档，或使用可信平台并单独控制额度和权限。

## FAQ

### ChatGPT Images 2.0 和 GPT Image 2 是一回事吗？

它们都和 ChatGPT 图片生成体验及 OpenAI 图像模型能力有关。普通用户关注 ChatGPT 里的图片功能，开发者关注 GPT Image 模型和 API。

### 图片生成额度是多少？

额度会随账号和官方策略变化，以页面实际显示为准。

### 生成图可以商用吗？

要看平台条款、输入素材版权、输出内容是否包含商标或人物肖像，不能只看模型能不能生成。
