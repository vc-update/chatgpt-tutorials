## ChatGPT 写周报教程：从流水账变成结构化汇报

**适用人群：** 需要每周向上级汇报的职场人、实习生、项目成员、运营和销售岗位。

写周报最容易犯的错误是列一堆"做了什么"，却没有说清"结果和价值"。ChatGPT 的作用就是帮你把零散事项组织成有重点、有成果的结构化汇报。

**流程分三步：**

1. **输入本周工作事项。** 把本周做的事一条条丢给它，哪怕是流水账也没关系。
2. **生成结构化周报。** 让它按"本周成果、进行中事项、下周计划、需要协调的资源"重新组织。
3. **调整语气和突出成果。** 追问让它把数据前置、语气更正式，或者更口语化。

**可复制 Prompt 模板：**

你是我的职场写作助手。请把下面的本周工作事项整理成一份结构化周报。

我的岗位：【岗位，如运营专员】
本周事项：【逐条列出你做的事，可以是流水账】
汇报对象：【直属领导 / 跨部门 / 客户】
风格要求：【简洁正式 / 有数据支撑 / 突出成果】
字数：【如 300 字左右】

要求：
1. 分为"本周主要成果、进行中事项、下周计划、需要支持的资源"四部分；
2. 有数据的地方把数据放在句子前面；
3. 不要写空话套话，每条都要能看出具体产出。
**优化示例：** 如果生成的周报太像 AI、读起来很"标准件"，可以追问："用更自然的口吻改写，像我平时跟领导汇报的语气，去掉'赋能''闭环'这类词。" 更多办公写作场景可参考 AI写作办公教程。

> 提示：写周报时不要把公司机密、客户名单、未公开数据原文粘贴进去，可用"某客户""A 项目"等代称。

## ChatGPT 做 PPT 教程：先让 AI 生成大纲，再拆成每页内容

先说清楚一个常见误区：ChatGPT 更擅长帮你生成 PPT 的**内容框架**——大纲、每页标题、要点和演讲稿，而不是直接产出一个可以打开就用的、排版精美的 PPT 文件。真正的排版还是要在 PowerPoint、WPS、Keynote 或专门的 AI PPT 工具里完成。

正确用法是"两步走"：先出大纲，再逐页拆内容。

**第一步——生成大纲 Prompt：**

我要做一份 PPT，主题是【主题】，用途是【汇报 / 课程讲解 / 项目复盘】，
听众是【目标听众】，时长约【分钟数】。
请先给我一个 PPT 大纲，包含封面、目录、每个章节标题和页数建议，控制在【X】页以内。
**第二步——拆分每页内容 Prompt：**

基于上面的大纲，请把第【N】页展开：
给出这一页的标题、3-5 个要点（每条不超过 20 字）、以及一段 60 字左右的演讲稿。
风格：【简洁商务 / 活泼课堂 / 严谨复盘】
**三种常见 PPT 的差异：**

- **汇报型：** 重点在结论前置、数据支撑，页要点要精炼，演讲稿要能撑起细节。
- **课程型：** 重点在逻辑递进和举例，可以让它多给案例和类比。
- **项目复盘型：** 按"目标—执行—结果—问题—改进"组织，让它帮你提炼经验和教训。

## ChatGPT 写论文教程：选题、提纲、文献综述、改写润色的正确用法

先划重点：**ChatGPT 可以做论文的辅助工具，但不能替你研究、不能代写、更不能伪造参考文献。** 它生成的"引用"经常是看似真实、实则不存在的，必须逐条到数据库核对。把它当成一个会发散思路、会润色语言的助手，而不是枪手。

合规的用法主要有这几类：

- **选题发散：** "围绕【研究方向】，帮我列出 8 个具体、可研究、有数据来源的选题方向，并说明每个的研究切入点。"
- **搭建提纲：** "我的论文题目是【题目】，帮我列一个包含引言、文献综述、方法、结果、讨论、结论的提纲，每部分写清楚要论证什么。"
- **梳理研究思路：** 把你的想法讲给它听，让它帮你检查逻辑漏洞、指出论证薄弱的地方。
- **语言润色：** "把这段话改得更符合学术书面语，保持原意，不要增加新观点。"（改完自己要逐句核对是否篡改了你的意思）
- **摘要优化：** "根据我的正文，帮我写一版 200 字的中文摘要，突出研究问题、方法和主要发现。"

**关于文献综述：** 可以让它帮你梳理某个领域的研究脉络和常见争议，但所有具体文献、作者、年份都必须自己去知网、Web of Science 等数据库核实，切勿直接采信它给出的引用列表。

学术诚信是底线。论文合规使用的更多细节，建议看 ChatGPT写论文合规指南。

## 图片生成 Prompt 怎么写？适合 GPT-image-2 等图像模型的提示词公式

图片生成的效果，很大程度取决于提示词写得够不够具体。一个好的图片 Prompt 通常包含这八个要素：

**主体 + 风格 + 构图 + 镜头 + 色彩 + 细节 + 比例 + 负面要求**

- **主体：** 画面主角是什么（人物、物品、场景）。
- **风格：** 写实摄影、扁平插画、水彩、3D 渲染、赛博朋克等。
- **构图：** 居中、三分法、特写、全景。
- **镜头：** 广角、微距、俯拍、逆光。
- **色彩：** 主色调、冷暖、明暗。
- **细节：** 材质、光影、氛围、表情。
- **比例：** 1:1 头像、16:9 封面、9:16 竖版海报。
- **负面要求：** 不想要的元素，比如"不要文字、不要多余的手指"。

**通用中文模板：**

主体：【一个戴眼镜的年轻女性程序员，侧脸微笑】
风格：【日系清新插画风】
构图：【半身特写，人物居左，右侧留白】
镜头/光线：【柔和自然光，逆光轮廓】
色彩：【低饱和暖色调】
细节：【发丝清晰，皮肤质感自然】
比例：【1:1】
负面要求：【不要文字水印，不要变形的手】
**分场景快速套用：**

- **头像：** 1:1，半身或特写，风格统一，背景简洁。
- **海报：** 9:16 或 3:4，主体突出，预留标题文字位置。
- **插画：** 明确风格关键词，强调氛围和色调。
- **产品图：** 干净背景、聚焦材质、加"棚拍光""白底"。
- **封面图：** 16:9，主题一目了然，构图给标题留空。

在支持图像功能的入口里可以尝试，比如页面显示支持 GPT-image-2 的 [snakegpt.vip](https://www.snakegpt.vip/)，具体可用模型以平台实际显示为准。想更系统学习，可看 GPT-image-2 图片生成教程。

- ❌ **别过度依赖。** AI 是助手不是替身，最终判断和责任在你自己。

## 常见问题 FAQ

### Q1：ChatGPT 网页版要下载吗？
不需要。用电脑或手机浏览器打开对应网页即可使用，App 只是把网页功能装进本地，新手从网页版起步完全够用。

### Q2：国内打不开 ChatGPT 官网怎么办？
官网访问是否顺畅取决于你的网络条件。官网不稳定时，可以选择国内可访问的多模型入口作为替代方式，如 [snakegpt.vip](https://www.snakegpt.vip/) 或 [gptcat.cc](https://gptcat.cc/)，具体可用功能以页面实际显示为准。这些是第三方平台，不是官方入口。

### Q3：ChatGPT 能写论文吗？
可以辅助选题、搭提纲、润色语言、优化摘要和梳理思路，但不能代替你研究，不能伪造文献和数据。所有引用必须自己到数据库核实，务必遵守学术诚信要求。

### Q4：ChatGPT 能直接做出完整 PPT 吗？
它更适合生成大纲、每页标题、要点和演讲稿。可以直接打开使用的精美 PPT 文件通常还需要你在 PowerPoint、WPS 或专门的 AI PPT 工具里排版。

### Q5：图片生成 Prompt 怎么写才好用？
按"主体+风格+构图+镜头+色彩+细节+比例+负面要求"的结构写，越具体效果越稳。可套用本文的中文模板，在页面显示支持 GPT-image-2 的入口尝试，以平台实际显示为准。

### Q6：用 ChatGPT 写的周报会不会一看就是 AI 写的？
会，如果不加处理。追问让它"用我平时的口吻改写、去掉套话、数据前置"，并自己再润一遍，就能显著降低"AI 味"。

### Q7：ChatGPT 中文版和官网有什么区别？
官网是 OpenAI 提供的原生环境；所谓"中文版"多指面向中文用户、国内可访问的第三方入口，中文问答更方便，但不是官方产品，账号和支付规则以平台自身说明为准。

### Q8：手机浏览器能用 ChatGPT 吗？
能。在手机 Safari 或 Chrome 里打开官网页面或国内可访问平台即可，免下载 App。想要接近 App 的体验，可把常用页面"添加到主屏幕"。
