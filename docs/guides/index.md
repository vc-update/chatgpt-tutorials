## 通用任务模板

```text
目标：我最终要得到什么结果？
材料：只能使用哪些文字、文件或数据？
对象：结果给谁看，使用场景是什么？
格式：表格、清单、正文还是逐页大纲？
限制：字数、语气、不能推断的内容是什么？
复核：哪些事实、数字、引用需要单独标记？
```

还没有完成第一次对话，可先回到[ChatGPT教程中心](/chatgpt/)；需要代码、API 或 CLI 内容，请进入[开发者栏目](/developers/)。
