## 一、图片 Prompt 的基本结构

一个好用的图片提示词通常包含：

| 模块 | 示例 |
|:---|:---|
| 主体 | 一位正在使用电脑的年轻设计师 |
| 场景 | 明亮的现代办公室 |
| 风格 | 写实、干净、科技感 |
| 构图 | 半身像，主体居中 |
| 细节 | 桌面有笔记本、咖啡、草稿纸 |
| 限制 | 不要文字水印，不要畸形手指 |

模板：

```text
请生成一张图片：主体是[主体]，场景是[环境]，风格为[风格]，构图要求[构图]，细节包括[细节]，避免[限制]。
```

## 三、常用场景模板

### 小红书封面

```text
请生成一张小红书风格封面图，主题是“ChatGPT办公效率提升”，画面明亮、干净、有科技感，保留充足留白，适合后期添加标题，不要出现乱码文字。
```

### 产品介绍图

```text
请生成一张 SaaS 产品介绍图，主体是一块简洁的 AI 工作台界面，背景为现代办公场景，色彩清爽，构图适合网站首屏展示，不要真实品牌标识。
```

### 教程配图

```text
请生成一张教程文章配图，主题是“新手学习 ChatGPT”，画面包含电脑、对话界面和学习笔记，风格真实自然，避免夸张科幻。
```

## 四、提示词优化技巧

- 不要只写“生成一张好看的图”。
- 明确用途：封面、配图、海报、头像、插画。
- 写清比例：横图、竖图、方图。
- 把不想要的元素写进限制。
- 第一版不满意时，要求保留构图，只改颜色、细节或风格。
