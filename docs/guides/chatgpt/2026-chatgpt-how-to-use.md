## 二、第一次使用ChatGPT：按这个流程来

1. 打开入口。
2. 注册或登录账号。
3. 选择模型。
4. 输入任务，不要只写一句“帮我写一下”。
5. 根据结果继续追问，让它修改、补充、压缩或换格式。

第一次提问可以这样写：

```text
我想完成：[你的任务]
背景是：[你的场景]
目标读者/使用对象是：[谁会看]
请输出：[你想要的格式]
要求：[语气、长度、限制、注意事项]
```

示例：

```text
我想写一篇介绍ChatGPT使用方法的文章，目标读者是零基础新手。请输出一个详细大纲，要求包含入口选择、注册流程、提问技巧、办公场景和FAQ，语气自然，不要夸张营销。
```

## 三、ChatGPT使用方法：按场景直接套

### 3.1 写文章

```text
请围绕「ChatGPT怎么用」写一篇1500字教程，目标读者是零基础用户。结构包括：痛点、入口选择、使用步骤、Prompt模板、常见问题。语气清晰务实，不要堆砌术语。
```

进阶追问：

```text
请把上面的文章改得更像真人写作，减少重复表达，并补充3个真实办公案例。
```

### 3.2 写周报

```text
请把下面的工作记录整理成周报，输出格式为：本周完成、关键数据、遇到问题、下周计划、需要支持。语气专业简洁。
```

### 3.3 总结文档

```text
请阅读下面资料，输出：300字摘要、5个关键结论、3个行动建议、风险点、需要继续确认的问题。
```

如果你经常处理长文档，可以选择支持文件上传和多模型的入口，例如 [GPTCat](https://gptcat.cc)；如果是代码项目或长任务，可以关注 [ZeoGPT](https://www.zeogpt.com/register?ref=MRNWDKC3)。

### 3.4 学习知识

```text
请用费曼学习法解释 [概念]。先用一句话解释，再用生活类比说明，最后给我5道自测题和答案。
```

### 3.5 写代码和查Bug

```text
你是资深工程师。下面是我的运行环境、报错信息和相关代码。请先判断最可能原因，再给出最小修改方案，最后告诉我如何验证。
```

代码类任务不要只贴截图，最好提供可复制的文本、版本号和复现步骤。

## 四、让ChatGPT答案变好的追问技巧

第一轮回答普通很正常。真正的效率来自追问：

- “把上面的内容改成表格。”
- “只保留最重要的5点。”
- “给我一个可直接复制到飞书的版本。”
- “用更适合新手的语言重写。”
- “指出这个方案可能失败的地方。”
- “先问我3个问题，再继续写。”
- “用更自然、更少AI味的语气重写。”

你可以把 ChatGPT 当作一个需要不断校准的协作者。你越会反馈，它越好用。

## 五、ChatGPT技巧：新手和高手的差距

| 维度 | 新手做法 | 更好的做法 |
|:---|:---|:---|
| 提问 | 帮我写一篇文章 | 说明读者、目的、平台、结构、语气 |
| 修改 | 不满意就重开 | 指出哪里不满意，让它定向修改 |
| 输出 | 只要一段文字 | 要表格、清单、步骤、模板 |
| 验证 | 直接复制 | 要它列出不确定点并人工核对 |
| 复用 | 每次重新问 | 保存高质量 Prompt 模板 |

## 七、常见问题

### ChatGPT怎么用最简单？

最简单的方法是套模板：背景 + 目标 + 材料 + 输出格式 + 限制条件。只要这五项说清楚，答案质量会明显提升。

### ChatGPT可以用于办公吗？

可以。最适合的办公场景包括周报、会议纪要、邮件、方案大纲、资料总结、数据分析和 PPT 大纲。

### ChatGPT回答不准怎么办？

补充上下文，让它列出不确定点，并要求给出验证方法。涉及事实、法律、医疗、财务时必须人工核对。

### 新手应该先学Prompt还是先学模型？

先学 Prompt。模型选择会影响上限，但 Prompt 决定你能不能稳定拿到可用答案。
