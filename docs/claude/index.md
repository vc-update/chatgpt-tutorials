## Claude Code最小安全流程

1. 在 Git 分支或项目副本中开始。
2. 先只读分析目录和启动命令。
3. 修改前让工具列出计划与影响范围。
4. 修改后运行测试、构建并检查 `git diff`。
5. 删除、部署、数据库和密钥操作必须人工确认。
