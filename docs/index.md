## ChatGPT 新手使用方法：五步完成第一次对话

<ol class="step-list">
  <li><strong>确认入口性质。</strong>官方页面、第三方中文工具和教程站的服务主体不同，先看域名、主体和隐私说明。</li>
  <li><strong>新建一个对话。</strong>先用普通问答测试，再根据任务决定是否使用文件、图片或更高推理设置。</li>
  <li><strong>用中文写清任务。</strong>说明要完成什么，而不是只写“帮我处理一下”。</li>
  <li><strong>指定输出要求。</strong>补充读者、语气、长度、格式、资料范围和不能出现的内容。</li>
  <li><strong>复核并继续追问。</strong>检查事实、数字、引用和隐私，再要求模型补充、压缩或改写。</li>
</ol>

一个通用中文 Prompt 可以这样写：

```text
你是【角色】。请帮我完成【任务】。
背景是【必要信息】，目标读者是【目标读者】。
请用【表格/分点/指定字数】输出，并遵守【限制条件】。
不确定的内容请明确标记，不要编造来源。
```

需要更多模板，可以进入 [ChatGPT Prompt 与办公模板](/chatgpt/chatgpt-prompt-templates-writing-office-guide-2026)。
