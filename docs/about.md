# 关于本站

`chatgpt-tutorials.com` 是面向中文用户的独立第三方教程站，主要整理 ChatGPT 的入门方法、中文版与网页版辨别、Prompt、图片生成、Codex 和 API 实操。本站不是 OpenAI 官方网站，也不提供模型账号、对话或 API 服务。

## 谁在维护内容

本站内容由 **ChatGPT教程编辑组** 维护。我们使用组织署名，是因为文章通常会经过选题、操作核验、文字编辑和发布检查，不虚构个人作者、学历、职业或官方资历。

每篇核心教程尽量标注发布日期和最后核验日期。页面中的“最后更新”表示该页内容或链接在对应日期经过修订，不代表第三方平台此后永久保持相同状态。

## 我们写什么

- 新手可以照着完成的分步教程，而不只是入口列表。
- 中文写作、办公、论文、图片与编程等具体场景的 Prompt 和复核清单。
- 官网、第三方中文工具、网页版、客户端和 API 的身份与用途区别。
- 模型或功能变化后的内容修订、过期说明和风险提醒。

## 信息从哪里来

编辑时优先参考 OpenAI 等服务方的公开产品页、帮助文档和开发者文档，并通过浏览器或命令行检查公开页面是否可访问、链接是否跳转。第三方工具的功能名称、模型列表和注册方式只按其公开页面或实际界面记录，并注明核验日期。

页面可访问不等于长期稳定，也不能单独证明底层模型来源、服务质量或隐私安全。没有完成独立验证的能力，我们不会写成已经验证的事实。

## 推荐链接与商业关系

部分文章会按使用场景介绍 SnakeGPT、GPTCat、ZeoGPT 或 ZeoAPI，并可能使用带推荐参数的链接。读者点击或注册后，本站可能获得推广收益；这不会增加文章中声称的功能，也不构成官方背书。

推荐不会代替风险判断。使用第三方平台前，请自行查看服务条款、隐私政策、账号规则和实际功能，不要上传密码、私钥、身份证、银行卡或未脱敏的商业资料。

## 如何纠错

本站目前未开放评论区或公开联系表单。发现页面存在错误、失效链接、身份混淆或过期信息时，可通过域名注册信息中的公开渠道，或项目未来开放的公开反馈入口提交问题。本站收到可复核证据后会修订内容，并在[最新更新](/latest/)记录重要改动。
