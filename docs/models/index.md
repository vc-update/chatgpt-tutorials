## 比较模型时看什么

1. 使用相同输入材料、目标和输出格式，避免用不同 Prompt 得出失真的结论。
2. 分别记录事实准确性、格式遵循、上下文保持、图片或文件支持和响应稳定性。
3. 区分官方网页、API、CLI 与第三方聚合平台，核对当前实际显示的模型名称。
4. 不把一次测试结果写成长期结论；重要任务至少复核一次来源、数字和代码输出。
